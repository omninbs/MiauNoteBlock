## 档位 → Θ 映射（presence 使用）
- Θ(Q) = -3 + 15·(1-Q) dB
- 各档：0.60→+3.0dB / 0.40→+6.0dB / 0.20→+9.0dB / 0.05→+11.25dB
- Q≥0.99 → 仅去重早退（跳过 margin 引擎）
- 默认档 0.60（高质量）对应文档默认 Q=0.7 附近的轻度压缩

## v6.0 引擎实现要点

### Stage 0 物理参数表（均标 `[UNVERIFIED]`，按文档 §1.2）
- 新增 `VO` 表（16 内置乐器 + custom）：每项 `{L 响度, tau 衰减秒, oct 八度偏移, atk 攻击秒, kind: 'pitched'|'perc'|'noise'|'hi'}`；custom 取中性值（L=1, tau=1, oct=0）+ unknown_timbre 标记
- A-weighted 响度 `wA(f)`（§1.3 公式，`[VERIFIED]`）；Bark `z(f)=13·atan(0.00076f)+3.5·atan((f/7500)²)`（Zwicker-Terhardt）
- 频谱模板 E(z)：Bark 网格 0–24、步长 0.5（49 点）。pitched = 4 谐波 bump（权重 [0.5,0.3,0.15,0.05]，σ≈1 Bark ≈2 Bark 带宽）；snare 宽带 2–20 Bark 平铺；kick 1–5；click 15–20；custom 全带平铺。模板归一 ΣE=1
- 不对称扩散矩阵 `S`（§3.2，Z×Z 预计算）：`S_dB = -12·max(0,z-z') - 27·max(0,z'-z)`（向上掩蔽缓、向下陡——删高保低物理基础）

### Stage 1 派生与事件流
- `V(n)=velocity/100`；`f(n)=440·2^((key+oct+pitch/100-69)/12)`；tau/T_atk/L 查表
- 音符按 tick 排序；活跃集 `[t_n, t_n+6.9τ_n]`（tick→秒，10 TPS）

### Stage 2 伪延音检测（独立于 v4.0 的检测）
- 同 instrument + round(effPitch)（半音精度，oct 敏感）+ 间隔 ≤2 tick；窗口内出现同 instrument 异 pitch → 和弦消歧中断
- 合并规则（§6.3）：Q≥0.5 组完全不动；Q<0.5 且 compFactor≤3 → 合并为保首音 + velocity 补偿（`compFactor=sqrt(Σe^{-t_i/τ})`，clamp 0-100）；compFactor>3 → 保首 + 中位 2 个 retrigger 分摊补偿
- 合并后保留音 margin 按补偿后能量重算（延音本身可闻则主循环天然不选）；**I4 对合并组豁免**（能量补偿延续 tick 内容，同 v4.0 C2 例外）

### Stage 3 掩蔽场 + margin（事件驱动）
- 每个不同 onset tick T 预计算 `P_T(z) = Σ_{active@T} E_m(z)·e^{-(T-t_m)/τ_m}·L·V`（双耳：|pan差|>50 时掩蔽者 ×0.6）；预计算 `spread(P_T) = S·P_T`
- `margin_mask(n)` = max over 检查点 t ∈ {t_n} ∪ {邻域 onset（时间重叠 + 同 ±2 Bark supp）} of max over z∈supp(E_n) of `10·log10( E_n(z)·env_n(t)·L·V / (spread(P_T)[z] − n 自身扩散) )`
- 攻击窗口 `[t_n, t_n+T_atk]` 内检查点 **+12dB**（抬高瞬态可闻性，保护 hat/click/snare onset，§4.2）
- `margin_abs(n)=10·log10(L·V·W(f)/P_ref)`，P_ref=全曲 max；`margin = min(margin_mask, margin_abs+40)`
- 复杂度：检查点=事件数规模，Z=49 常数，满足文档 O(E·k) 目标；删除后按脏 tick 惰性重建 P_T

### Stage 4 增量删除主循环
- 队列按 margin 升序，平局全序（L·V → layer → key，全升序，确定性）
- 弹出 → 不变式检查 → 删 → 受影响集 R（±2 Bark 且时间重叠）重算 margin → 队列更新（惰性删除 + 代际计数防陈旧项）
- margin < -6dB：**无条件删**（I7 推广，跳过全部不变式）；I7（L·V·W(f) < 0.02）预删，优先级最高
- lighten 层：需 margin ≤ Θ-3dB 才可删（保守偏置，替代旧 cost×2 语义）；custom 乐器需 margin ≤ Θ-6dB（unknown 降权偏保守）
- 审计自证计数：`transient_rescued`（+12dB 救回）；`unmask_rescued` / `incremental_requeued`（解掩蔽后 margin 上移出队）

### 不变式（docs §5.4，本引擎独立一套）
- I1: inst==2 全保；I2: inst==3 且 floor(tick/tpb)%2==1（拍 2/4 backbeat）全保
- I3': 同 tick:inst 组内最低 effPitch 乐音不被阀门删（根音保护）
- I4: 原非空 tick 删除后仍非空（合并组豁免）
- I5': 同 instrument 存活数 ≥3（绝对下限，注意是 instrument 维度非 layer）
- I6': 每 4 拍窗口内 margin 最大音不删（防御性显式化）
- I7: 物理闻阈无条件删，优先序最高

### Stage 5 审计（§10）
`audit = { settings:{Q,theta_dB}, margin_histogram:{<-6 / [-6,0) / [0,Θ)}, invariant_checks, rescued_by_fix, pseudo_sustain:{detected,merged,avg_comp,kept_2}, output:{kept,removed,ratio} }` — 供测试断言与结果消息。
