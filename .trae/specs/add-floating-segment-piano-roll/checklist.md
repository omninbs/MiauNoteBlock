# Checklist

## 片段分割弹窗

- [ ] 弹窗中不再出现原两段长说明（`.seg-split-hint` / `.seg-split-note`）
- [ ] 存在且仅存在一条警告：「对 NBS 数据处理可能效果很差」
- [ ] 复选框与颗粒度选项均为短语，无解释性长句
- [ ] 「合并内容相同的轨道」默认未勾选，执行分割时不合并
- [ ] 主动勾选后仍按原签名规则合并
- [ ] 弹窗全部文案在 en-US 下无中文残留，切换语言即时生效

## 浮动窗口基础

- [ ] 双击片段打开该轨道的浮动钢琴卷帘窗口，且不再退出片段模式
- [ ] 同一轨道重复双击复用已有窗口并切换内容，不产生重复窗口
- [ ] 不同轨道可同时打开多个窗口
- [ ] 标题栏可拖动，窗口始终保留可抓取区域
- [ ] 边缘/角可缩放，画布随尺寸重排重绘，且有最小尺寸
- [ ] 最小化后仅剩矮窄标题栏，默认堆叠在右上角，间距统一
- [ ] 最小化标题栏可拖动，且后续最小化窗口不覆盖已移动的标题栏
- [ ] 最大化/还原正确，双击标题栏行为一致
- [ ] 点击窗口置顶；系统弹窗（设置/确认）仍显示在其上方
- [ ] 关闭重开（含刷新页面）恢复位置、尺寸、最大化/最小化状态

## 渲染

- [ ] Y 轴为音高、X 轴为时间，小节网格与标尺正确
- [ ] 同层同音高逐 tick 连续音符显示为一条长音符，长度等于连续区间
- [ ] 长音符的音色图标与文字只出现在起始端，无左右分置
- [ ] 重叠位置图标错位叠放，每个图标至少 1/2 面积可见
- [ ] 音符底色取最上层音符颜色
- [ ] 重叠数量增减时图标位置有平滑动画过渡，无跳变
- [ ] Ctrl+滚轮缩放、水平/垂直滚动正常

## 编辑

- [ ] 绘制音符实时写回片段，主视图同步
- [ ] 删除音符（含重叠时只删最上层）实时写回
- [ ] 拖动移动音符时吸附网格生效
- [ ] 拖动右边缘改变长度会真实增删连续音符，并与相邻同音正确合并/拆分
- [ ] 框选后批量移动/删除生效
- [ ] 复制/粘贴按相对偏移与网格吸附生效
- [ ] 网格档位（1 tick / 8 tick / 16 tick）切换后绘制、移动、粘贴均对齐
- [ ] 默认只操作最上层音符
- [ ] Alt+悬浮+滚轮可临时切换目标层，移出 1 秒后恢复
- [ ] 点击音符使其置顶，且不改变 NBS 和弦数据顺序
- [ ] 力度竖条与数值输入均能修改选中音符力度
- [ ] 无选中时调整力度只影响后续绘制的默认值
- [ ] 每次编辑都进入撤销栈，Ctrl+Z/Ctrl+Y 在窗口与主视图同步生效

## 播放与参考

- [ ] 默认与主播放头同步，不重复发声
- [ ] 开关滑块切到「仅本窗口」后片段内循环播放，主界面状态不受干扰
- [ ] 切回同步后播放头立即对齐主界面 tick
- [ ] 可选择同轨其他片段作为半透明参考，参考片段不可编辑
- [ ] 取消参考后仅显示当前片段

## 国际化

- [ ] 窗口标题、菜单、提示、控制器标签均有词典条目
- [ ] 窗口打开状态下切换语言即时重译
- [ ] canvas 内文字（音名、力度、提示）随语言切换重绘

## 重构

- [ ] 页面以 file:// 打开时所有模块正常加载，控制台无报错
- [ ] `window.WebNBS` 共享 API 可用，无重复定义
- [ ] Node 回归结果与重构前基线一致：39 个 NBS × 3 档颗粒度无重复音符、无重叠、无空片段，轨道合并数一致
- [ ] 无头浏览器端到端流程通过：导入 → 片段模式 → 开窗编辑 → 撤销 → 关闭 → 分割 → 退出/重进
- [ ] `node --check` 所有脚本通过
- [ ] `npm run build` 成功，`blbl-toy/index.html` 双击可用且包含全部模块
- [ ] `src/index.html` 版本号已更新
- [ ] 截图验收：1280×800 下窗口层次清晰、最小化栏不遮挡工具栏与状态栏
