# Checklist

## 设置与主题
- [ ] 设置弹窗内的滑块不再有外层容器背景/边框
- [ ] 主题预设按钮已缩小且尽可能单行排布，不出现大面积留白
- [ ] 设置-个性化提供「自定义主题色」，选定后立即生效并持久化

## 调色板
- [ ] 项目中不再存在原生 `input[type=color]`
- [ ] 片段轨道色点、背景色等颜色设置均打开自研调色板
- [ ] 调色板支持色相环、亮度/饱和度面板、HEX、RGB 输入与实时预览
- [ ] 调色板在 `file://` 离线环境可用（不依赖 CDN）

## 片段轨道面板
- [ ] 每个音量旋钮右侧有横向电平表
- [ ] 播放时有音符发声的轨道电平跳动，静音轨道为 0，停止后平滑归零
- [ ] 旋钮支持触屏纵向拖动调值，鼠标滚轮仍可用

## 片段拖拽与重叠
- [ ] 拖动片段/改长度时不显示白色虚线吸附框
- [ ] 拖动过程外观实时跟随鼠标，不回弹
- [ ] 起点越界 clamp 到 0，长度最小 1 tick，右端不受限制
- [ ] 同轨片段可重叠，start 更晚者覆盖更早者
- [ ] 重叠区域点选命中上层片段
- [ ] 保存/读取/导出/自动保存后重叠、颜色、音量、高度元数据完整恢复
- [ ] `segmentCompose` 在重叠区按 start 更晚优先缝合音符

## 片段模式交互
- [ ] 点击编辑区空白处可移动播放头
- [ ] 播放中右键不再跳到播放指示器，播放继续

## 自动分割
- [ ] 无重复片段的轨道自动分割后不产生新片段
- [ ] 有重复结构的轨道仍按原规则分割，音符零丢失

## 钢琴卷帘窗口
- [ ] 参考片段按钮、参考叠加绘制、选择菜单均已删除
- [ ] 标题显示「测试版」标签
- [ ] 「仅本窗口」时主窗口暂停，快捷键只作用于聚焦窗口且不穿透
- [ ] 调整窗口大小/最大化/还原时不再重放入场动画，无闪烁
- [ ] 左侧钢琴悬停/点击用亮度变化反馈，无边框
- [ ] 黑键绘制在上层且右侧无白块
- [ ] 音符仅显示纯色，无纹理叠加
- [ ] 放置/删除动画平滑插值
- [ ] 音符可正常命中、选中、拖动、改长度
- [ ] 正常钢琴音域外的键仍显示且可放置
- [ ] 音符编辑后若层不足自动扩展片段 NBS 轨道层

## 缩放与移动端
- [ ] 音符行高可调，桌面 Ctrl+滚轮纵向、Shift+滚轮横向
- [ ] 触屏双指逐轴缩放生效，主视图也支持双指缩放
- [ ] 手机/小平板进入全屏钢琴卷帘页，带返回按钮
- [ ] 触屏长按片段可进入编辑

## MIDI 延音与音色拟合
- [ ] 延音轨道选择旁有「带音量变化的延音」开关且默认开启，配置可持久化
- [ ] 开启后延音音符 velocity 按音色包络衰减
- [ ] 持续型音色延音音量保持平稳，不快速淡出
- [ ] 缺失 SF2 数据时安全降级并只警告一次

- [ ] GM→NBS 映射已重写，钢琴默认使用电钢琴
