# 片段编辑器与钢琴卷帘窗口全面改造 Spec

## Why

片段模式目前存在三类系统性问题：一是交互「回弹/幽灵虚线/右键误跳转」等操作体验缺陷；二是片段数据模型不支持重叠，导致编辑与保存语义受限；三是双击片段打开的钢琴卷帘浮窗在命中测试、缩放、移动端布局、播放同步与重建闪烁上都有硬伤。同时 MIDI 导入的「伪延音」只是等音量重复音符，没有根据真实音色包络做淡出，音色拟合表也存在明显错配（如钢琴映射到 NBS 铃铛/竖琴而非电钢琴）。本 Spec 一次性把这些功能与缺陷收敛到一套明确的规则上。

## What Changes

- 设置界面：移除滑块容器背景；主题色预设按钮缩小并单行排布；所有颜色选择改用自研统一调色板组件（vendored iro.js），不再依赖原生 `input[type=color]`。
- 片段模式：左侧轨道栏为每个音量旋钮增加横向实时电平表（基于真实音频分析）；旋钮支持触屏纵向拖动。
- 片段编辑：拖动/改长度不再绘制白色虚线吸附框，改为实时移动实体外观；越界直接 clamp 不回弹；支持同轨片段重叠（start 更晚覆盖更早），保存/读取/导出/自动保存全部正确保留重叠、颜色、音量等元数据。
- 片段模式：点击编辑区空白处即可 seek；修复播放时右键导致跳到播放头的问题。
- 自动分割：轨道内无重复片段时不分割（整轨保留一个片段）。
- 钢琴卷帘浮窗：删除「参考片段」功能与按钮；修正「仅本窗口」语义与快捷键作用域；标题加「测试版」标签；重做左侧钢琴键高亮与黑键几何；音符放置/删除改为插值动画；音符仅显示纯色（不显示纹理）；音符编辑后自动扩展片段轨道层数；支持音符纵向高度调整与双指/Ctrl+Shift 缩放；手机/小平板改为全屏页面并提供返回；修复调整窗口大小导致入场动画重播的闪烁；修复音符命中与移动。
- MIDI 延音：新增「带音量变化的延音」开关（默认开），根据 Python 分析 `FluidR3_GM.sf2` 得到的真实包络数据自动决定淡出速度/时长/曲线；重写延音轨道默认识别与音色拟合默认映射；延音轨道弹窗的「重置配置」改为预设下拉（全部可能延音 / 仅明显延音）。
- 触控适配：新增 UI 全部检查 `touch-action`、命中尺寸、双指缩放与长按逻辑，桌面/手机/平板布局正确。
- **BREAKING**：片段不再禁止重叠；同一 lane 内原先「回退原 lane/放弃提交」的规则被「clamp + 允许重叠」取代。
- 版本管理：先在 `main` 提交现有未提交改动，再新建 `feature` 分支；每完成一个大功能提交一次，不 push；最终验收通过后合并回 `main`。

## ADDED Requirements

### Requirement: 设置界面滑块容器去背景与主题预设紧凑化
系统 SHALL 移除设置弹窗内滑块外层容器的背景与边框，只保留轨道与 accent 填充。

#### Scenario: 打开设置-个性化
- **WHEN** 用户打开设置并切换到个性化标签页
- **THEN** 所有滑块轨道不再出现额外容器底色/描边，滑块视觉仅剩轨道与手柄

#### Scenario: 主题预设单行
- **WHEN** 设置-个性化标签页展示 UI 配色预设
- **THEN** 预设按钮尺寸缩小且尽可能在同一行排列，不出现大面积留白

### Requirement: 统一自研调色板组件（基于 iro.js）
系统 SHALL 提供统一的颜色选择组件 `ColorPicker`，替代项目内全部原生 `<input type="color">`，支持色相环/饱和度亮度面板、HEX、RGB 输入与实时预览，可离线运行。

#### Scenario: 修改片段轨道颜色
- **WHEN** 用户点击轨道栏色点
- **THEN** 弹出自研调色板；拖动色相环或亮度面板时轨道颜色与缩略图实时更新，确认后持久化

#### Scenario: 自定义主题色
- **WHEN** 用户在设置-个性化点击「自定义主题色」
- **THEN** 弹出自研调色板，选定颜色立即应用到 `--accent` 及派生变量

### Requirement: 片段轨道实时电平表
系统 SHALL 在片段模式左侧轨道栏每个音量旋钮右侧显示横向电平表，播放时按该轨道真实音频输出估算/分析得到实时电平，并带峰值保持与平滑回落。

#### Scenario: 播放时电平跳动
- **WHEN** 片段模式开始播放且该轨道有音符发声
- **THEN** 对应电平条实时上升，静音轨道保持为 0，停止播放后平滑归零

### Requirement: 无虚线实体拖拽与边界 clamp
系统 SHALL 在拖动片段（移动/改左边缘/改右边缘）时不绘制白色虚线吸附框，而是直接按预览位置绘制片段实体；越界时直接 clamp 到合法值，不回弹。

#### Scenario: 拖动片段到左边界外
- **WHEN** 用户将片段向左拖出编辑区
- **THEN** 片段起点停在 0，外观连续跟随鼠标，松手后保持 clamp 后的位置

#### Scenario: 调整长度超过可用范围
- **WHEN** 用户拖动右边缘超过歌曲末尾
- **THEN** 片段终点直接采用当前拖到的值（不限制右端，按歌曲长度自动扩展）

### Requirement: 同轨片段重叠与覆盖
系统 SHALL 允许同一片段轨道内片段时间区间重叠；渲染时 start 更晚的片段覆盖 start 更早的片段；命中测试与选择遵循最上层（start 最晚）优先。

#### Scenario: 两个片段重叠
- **WHEN** 同一轨道内两个片段区间重叠
- **THEN** 后一个（start 更大）片段完整绘制在上层，前一个被遮挡区域不可见且不可点击

#### Scenario: 重叠数据持久化
- **WHEN** 保存为 JSON / MNB / 自动保存后重新读取
- **THEN** 片段的 start/end 重叠关系、lane 颜色、lane 音量、lane 高度全部原样恢复

### Requirement: 片段模式空白处 seek
系统 SHALL 允许在片段模式编辑区的空白网格处点击/拖动来移动播放头指示器，与时间栏点击行为一致。

#### Scenario: 点击空白处
- **WHEN** 用户在片段画布空白区域单击
- **THEN** 播放头移动到点击 X 对应 tick，且不触发框选、不改变片段选择（除非拖动）

### Requirement: 右键不触发跳转
系统 SHALL 保证片段模式播放时右键不会把视口/播放头跳到播放指示器位置，右键仅用于上下文菜单。

#### Scenario: 播放中右键
- **WHEN** 播放进行中用户在片段画布右键
- **THEN** 播放继续、视口不发生跳转，仅弹出（或抑制）上下文菜单

### Requirement: 无重复不自动分割
系统 SHALL 在自动分割时，若某轨道不存在可复用的重复片段，则该轨道不切分，保留整轨一个片段。

#### Scenario: 内容各不相同的轨道
- **WHEN** 用户对一条完全没有重复结构的轨道执行自动分割
- **THEN** 该轨道不生成任何新片段，只保留原有整轨片段

### Requirement: 钢琴卷帘窗口修正
系统 SHALL 对浮窗执行以下规则：删除参考片段功能；标题显示「测试版」；「仅本窗口」时暂停主窗口播放且快捷键只作用于聚焦窗口；左侧钢琴键使用亮度变化（非边框）表示悬停/按下，黑键不出现右侧白块；音符仅使用纯色不叠加纹理；放置/删除动画使用插值；音符编辑导致层数不足时扩展片段对应 NBS 轨道层；音符命中与拖动正确。

#### Scenario: 仅本窗口播放
- **WHEN** 用户切换为「仅本窗口」并播放
- **THEN** 主窗口播放停止，只有该窗口内片段发声；空格等快捷键只影响该窗口

#### Scenario: 黑键几何
- **WHEN** 钢琴键栏渲染黑键
- **THEN** 黑键绘制在对应白键之上并横向缩短，不再出现黑键右侧的白色小方块

#### Scenario: 移动音符
- **WHEN** 用户按住音符拖动
- **THEN** 音符实时跟随、松手后落在网格吸附位置，命中区域与绘制位置一致

### Requirement: 音符纵向高度与缩放
系统 SHALL 支持调整钢琴卷帘一个音符行的显示高度；桌面用 Ctrl+滚轮（纵向）与 Shift+滚轮（横向），触屏用双指逐轴缩放；主视图也支持双指缩放。

#### Scenario: 桌面缩放
- **WHEN** 在浮窗内 Ctrl+滚轮
- **THEN** 音符行高变化；Shift+滚轮改变横向 tick 密度

#### Scenario: 手机双指缩放
- **WHEN** 在触屏设备上双指横向或纵向滑动
- **THEN** 分别对应横向时间缩放与纵向音高行高缩放，互不串扰

### Requirement: 手机/小平板全屏钢琴卷帘
系统 SHALL 根据可用屏幕尺寸判断，在手机与小平板上把钢琴卷帘呈现为全屏页面并带返回按钮；双击或长按片段进入该页面；桌面仍使用可拖动浮窗。

#### Scenario: 手机上打开片段编辑
- **WHEN** 手机用户长按/双击片段
- **THEN** 全屏打开钢琴卷帘页，左上角返回按钮可退出并回到片段模式

### Requirement: 窗口缩放不闪烁
系统 SHALL 在拖动调整浮窗大小期间不重放入场动画、不重建窗口 DOM，仅重排版画布。

#### Scenario: 拉伸窗口
- **WHEN** 用户拖动浮窗边角改变尺寸
- **THEN** 窗口内容连续重排，不出现整体重新淡入/闪烁

### Requirement: MIDI 带音量变化的延音
系统 SHALL 在 MIDI 导入的延音轨道选择旁提供「带音量变化的延音」开关（默认开启）；开启时，生成的延音重复音符按音色真实包络逐步降低 velocity，淡出速度/时长/曲线由预置 SF2 分析数据自动决定。

#### Scenario: 钢琴类延音
- **WHEN** 开启带音量变化的延音并导入钢琴音色轨道
- **THEN** 延音音符 velocity 沿衰减曲线下降，恰好在原音符结束处附近衰减到接近 0

#### Scenario: 持续型音色（管风琴/弦乐）
- **WHEN** 导入持续型音色轨道
- **THEN** 延音音量基本保持恒定（衰减极缓），不会被错误地快速淡出

### Requirement: SF2 音色特征数据
系统 SHALL 提供 Python 分析脚本与预生成的 `gm_sf2_profile.json`，包含每个 GM 音色的持续性、衰减时长、衰减曲线类型、能量包络采样点等，运行时零依赖读取。

#### Scenario: 数据缺失降级
- **WHEN** 运行时无法加载该 JSON
- **THEN** 使用安全默认值（保持旧行为）并在控制台给出一次警告，不影响导入

### Requirement: 延音轨道预设下拉
系统 SHALL 把延音轨道弹窗的「重置配置」按钮替换为预设下拉，至少包含「全部可能的延音」「仅选择明显的延音」，并支持恢复到用户手动勾选状态。

#### Scenario: 选择预设
- **WHEN** 用户在下拉中选择「仅选择明显的延音」
- **THEN** 勾选列表立即更新为明显延音轨道，数量摘要同步刷新

### Requirement: 重写 GM→NBS 音色拟合默认映射
系统 SHALL 依据 NBS 26 种乐器真实音色重写 `GM_TIMBRE_MAP` 的主乐器与槽位映射（如钢琴类映射到电钢琴 Pling/Elec 而不是竖琴/铃铛），同时保留用户手动设置优先。

#### Scenario: 导入钢琴 MIDI
- **WHEN** 导入 Acoustic Grand Piano 轨道且用户未手动设置
- **THEN** 默认拟合主乐器为电钢琴（NBS 15），音域与八度适配正确

### Requirement: 触控适配审查
系统 SHALL 为所有新增 UI 提供触控支持：可点区域最小 36×36 CSS px、`touch-action` 正确、旋钮纵向拖动、长按打开、双指缩放不触发页面缩放。

#### Scenario: 触屏操作设置与轨道栏
- **WHEN** 在触屏设备上操作设置弹窗、轨道栏旋钮、电平表区域
- **THEN** 所有控件可点、可拖，页面不发生意外滚动/缩放

## MODIFIED Requirements

### Requirement: 片段拖动提交
原「同 lane 重叠即放弃提交 / 移动时目标 lane 重叠回退原 lane」规则改为：允许重叠，按 start 排序决定覆盖顺序；提交时仅 clamp 起点 ≥ 0 与最小长度。

### Requirement: 片段渲染顺序
渲染顺序由「按 state.segments 数组顺序」改为「同 lane 内按 start 升序，start 相同时按 id 升序」，最后一个绘制即最上层。

## REMOVED Requirements

### Requirement: 参考片段功能
**Reason**: 用户明确要求删除浮窗内的参考片段功能与按钮。
**Migration**: 移除工具栏按钮、`refSegId` 状态、`getRefSeg`、参考片段绘制与 `spw-menu` 选择器；已保存布局中的相关字段忽略。
