# 创作辅助功能 与 音符查找/替换 —— 详细设计文档

> 文档版本：v1.0（设计初稿整理稿）

## 1. 概述与目标

在现有钢琴卷帘编辑器中为工具补充"可配置的放置/清除逻辑"，并新增全局"音符查找与替换"能力，使创作更高效、少重复劳动。

本次共两个功能模块：

1. **创作辅助功能悬浮窗**（模块 A）
   - 顶部工具栏新增「创作辅助」入口，点击展开悬浮窗。
   - 悬浮窗内容**跟随当前选中的工具自动切换**：
     - 默认工具 / 画笔工具 → 放置逻辑配置（普通放置 / 延音放置）。
     - 橡皮擦 → 清除逻辑配置（区域清除 / 连续清除）。
     - 选择工具 / 演奏模式 → 暂无配置，显示空状态提示。
2. **音符查找与替换**（模块 B）
   - 快捷键 `Ctrl+F` 打开固定于画布右上角的查找浮层。
   - 支持按 音色 / 音调 / 音量 属性组合检索，导航匹配项、全选匹配、批量替换。

## 2. 术语与现有技术基线

| 术语 | 说明 |
| --- | --- |
| tick | 音符的时间位置，x 轴，一格一个整数 |
| layer | 音轨/层级，y 轴 |
| 音符 | 数据结构 `{ id, tick, layer, instrument, key, velocity, pan, pitch }`，一格（tick, layer）至多一个音符（底层已强制） |
| key | 钢琴键序号（音调，内部为数字；UI 层用音名如 C4/D#3 表示） |
| velocity | 音量 0–100 |
| instrument | 音色 |
| 全局音量透明度 | 已存在的设置项（`settings-volume-opacity`），开启后音符不透明度按音量映射：`音量 0→0.2，100→1.0`（`_velocityToOpacity`），延音预览需复用该映射 |
| 工具 | `default`(默认) / `select`(选择) / `eraser`(橡皮擦) / `brush`(画笔) / `performance`(演奏模式) |
| 撤销 | 主流程　`pushUndo()`；一笔绘制 / 一次点按 = 一个撤销步骤 |

现有交互约束（必须遵守）：

- 触控与鼠标行为必须一致；触控「点击」等效按住 Ctrl 的多选语义。
- 画笔/橡皮仅在编辑区（`x >= 面板宽 && y >= 时间轴高`）生效。
- 双指平移、单指滑动绘制，互不干扰。
- 手机横屏（≤768px）隐藏顶部工具栏，功能迁移至右侧抽屉。
- JS / CSS 发布时更新版本号（如 `v=20260831a`），首页 `Cache-Control: no-cache`。

## 3. 模块 A：创作辅助功能悬浮窗

### 3.1 入口与形态

| 项 | 设计 |
| --- | --- |
| 入口（桌面端） | 顶部工具栏右侧「工具栏右侧区」新增按钮 `创作辅助`（图标建议 `fa-wand-magic-sparkles`），置于「功能」按钮旁；点击切换悬浮窗显隐，激活时按钮高亮 |
| 入口（移动端横屏 ≤768px） | 顶栏隐藏后，在右侧抽屉提供同名入口（遵循现有折叠迁移模式） |
| 形态（假设，待确认①） | **锚定浮动面板**：首次打开锚定在按钮正下方展开；支持拖动面板头部移动位置，位置写入 `localStorage`；点击面板外区域、`Esc`、点「×」关闭 |
| 层级 | 高于工具栏与画布，低于全屏模态弹窗（`.popup`） |
| 尺寸 | 宽度 280–320px，高度自适应（最大约视口高 70%，超出内部滚动） |

### 3.2 交互范式（设计稿核心：Tab 即开关）

- **不使用 Checkbox**；所有开关类功能使用**按钮式 Toggle**。
- **第一层为单选模式**，用 Tab 标签呈现；**切换到某个 Tab = 启用该模式并显示其子项配置**（"切到【延音放置】即开始用延音放置"）。
- 各工具的子项配置显示在对应 Tab 内容区：
  - **单选选项**（覆盖逻辑、区域形状、淡出样式、查找/替换 等）→ 单选按钮组（button group，视觉为分段按钮）。
  - **多选选项**（同类判定：音色/音调/音量）→ 可多选按钮组。
  - **数值项**（音量、延音长度、半径、最小音量等）→ 数字输入 + 可选滑块，非编辑态显示当前值。

### 3.4 放置逻辑（default / brush 工具）

#### 3.4.1 普通放置

- 每次放置 1 个音符，音量 =「音符音量」设定值（默认 100）。
- 行为与现有放置管线一致（点击放一个 / 画笔滑动逐格放），仅音量参数化。

#### 3.4.2 延音放置（伪延音）

**核心概念**：一次放置动作，在首音符所在格右侧同一层级连续放置 `N` 个**重复音调**的音符（tick 依次 +1，与首音符同 layer、同 instrument、同 key），播放时连续触发形成伪延音。放置总数 = `1 + N`。

**预览显示（Toggle，默认开）**

- 指针悬浮到可用格子时，在画布上以**半透明块**预览整组将放置的音符位置（首音符 + 延音音符），不落库。
- 若全局「音量透明度」已开启，各预览块的透明度在「预览基础透明度」之上，再乘各自音符的音量透明度映射（`_velocityToOpacity(velocity_i)`），即音量越小的延音音符预览越透明。

**延音长度**

- 取值 `N`（整数 ≥ 0，默认 5，不计首音符）。
- 放置组占 `N+1` 个连续格子；越界（tick ≥ 曲长上限）时截断。

**覆盖逻辑（单选，默认「直接覆盖」）**

| 模式 | 规则 |
| --- | --- |
| 直接覆盖 | 组内每个目标格若已存在音符，直接替换为本次音符 |
| 缩小长度 | 遍历组内格子时遇到**障碍音符**（该格已有音符）则提前终止；组内音符最大可达 tick ≤ `障碍tick - 留空长度K - 1`。即延音在障碍前 K 格处收尾，不越过障碍。K 仅在此模式下生效 |
| 禁止覆盖 | 组内目标格若已存在音符，**跳过该格**继续放置后续延音音符；首音符所在格被占用时整组不放置（假设⑦，待确认） |

**是否淡出（Toggle，默认关）**

- 关闭：组内所有音符音量 = 首音符音量（即「普通放置」的音符音量设定或起点音量）。
- 开启：按时间顺序从首音符音量单调递减至「最小音量」。
  - 第 `i` 个音符（`i = 0..N`，首音符为 0），进度 `p = i / N`（`N=0` 时不淡出）。
  - 音量公式：`velocity_i = V_start - (V_start - V_min) × ease(p)`，结果取整到 `1..100`。
  - `V_start` 取当前设定首音符音量；`V_min` 取「最小音量」（默认 10，0 本身在 MIDI 语义下等同静音，建议下限 1）。
- 示例（`V_start=90, V_min=10, 线性, N=5`）：`90, 80, 70, 60, 50, 40` —— 与设计稿示例（90,80,70…）一致。

**淡出样式（5 选 1 单选组）**：以 `p ∈ [0,1]` 为输入的自适应缓动函数，曲线上抛 `ease(p)`：

| 名称 | ease(p) |
| --- | --- |
| 线性 | `p` |
| 缓入 | `p²` |
| 缓出 | `1 - (1-p)²` |
| 二次缓入 | `p³` |
| 二次缓出 | `1 - (1-p)³` |

**放置动作与撤销**

- 一次「延音放置」（点按或画笔滑动经过一格时在该格生成一组）视为**一个撤销步骤**（组内所有音符同一 undo 批次）。
- 画笔滑动经过多格时，每经过一个新格触发一组放置；撤销粒度保持"一笔 = 一次撤销"不变（组内批量合并，滑动路径上多格仍按现有整笔撤销处理）。
- 试听提示音（`onNotePreview`）：保持现有行为，仅对首音符触发，延音音符不额外逐个试听（避免爆音）。

**与 default 工具的关系（假设，待确认⑥）**

- 设计稿标题为"「画笔工具」/「默认工具」的选项"，故延音/普通放置配置**同时作用于 default 与 brush**。default 工具当前"已有音符则不放置"的逻辑由「覆盖逻辑」接管。

### 3.5 清除逻辑（eraser 工具）

#### 3.5.1 区域清除

- **核心概念**：每次删除动作以指针所在格为中心，一次性清除形状范围内的所有音符。
- 交互：单击（触控按下即清，与现有触控擦除一致）或拖动（滑动路径经过的每个格都以该格为中心执行一次区域清除）。
- **清除半径 R**（整数 ≥ 0，默认 3，格子单位）。
- **区域形状**（单选组，默认圆形）：
  - 圆形：清除满足 `dx² + dy² ≤ R²` 的格子（`(dx, dy)` 为相对中心格偏移）；`R=3` 时覆盖 19 格。
  - 正方形：清除 `|dx| ≤ R` 且 `|dy| ≤ R` 的区域（边长 `2R+1`）；`R=3` 时覆盖 49 格。
- 越界格自动忽略；清空格无效果。

#### 3.5.2 连续清除（连锁删除同类）

- **核心概念**：每删除一个音符时，自动向四周扩散删除与其"连通的同类"音符，形成块状删除。
- **同类判定**（多选组：音色 / 音调 / 音量）：
  - 音色：`instrument` 相同。
  - 音调：`key` 相同。
  - 音量：`velocity` 相同（精确相等；±5 近似匹配列为二期增强，见「待确认⑤」）。
  - **多选组合逻辑（假设，待确认②）**：选中项**全部满足（AND）**才算同类；一组都不选时退化为仅删除目标音符本身（等同普通删除）。
- **扩散规则（假设，待确认③）**：从首次命中的音符出发，沿 **8 方向**向相邻格做级联泛洪（BFS），只扩展到满足同类判定的音符；删除目标音符本身计 1。
- **数量限制**（整数，默认 64）：一次连续清除动作累计删除的音符数**上限**，达到即停止扩散（防误删全曲）。
- 批量删除的动画/音效：若一次清除 ≤ 30 个音符播放删除动画（沿用现有 `removeNotesByIds` 的动画阈值策略），否则静默删除保证性能。

### 3.6 其他工具

- `select` / `performance`：悬浮窗显示空状态提示「该工具暂无创作辅助功能」，无任何配置项。

## 4. 模块 B：音符查找与替换

### 4.1 入口

- **快捷键 `Ctrl+F`**（主编辑视图，钢琴卷帘；FLS 视图中暂不注册——假设，待确认⑧）。
- 可选增强：在「功能」菜单中增加「音符查找 (Ctrl+F)」菜单项。
- 打开时**自动聚焦输入区**；再按 `Esc` 关闭浮层；重复 `Ctrl+F` 在「聚焦-关闭」间切换可选（建议：已打开时聚焦，避免误关）。

### 4.2 浮层形态

- **固定悬浮于画布右上角**（不随画布滚动/平移而移动），仿代码编辑器 Find 浮层。
- 支持拖动（拖动浮层头部），位置持久化（`localStorage`）。
- 宽度约 360–420px；内容超高时内部滚动。
- 打开期间**不影响**其他键盘操作（工具快捷键 D/S/E/B/P 等）；但文本输入控件获得焦点时应阻止全局快捷键误触发。

### 4.3 查找条件（多属性组合 = AND）

条件区支持同时设置三类属性，**同时满足**才算匹配：

| 属性 | 可设置方式 |
| --- | --- |
| 音色 instrument | 多选（下拉/按钮组，列出工程已用音色 + 其余可选音色） |
| 音调 key | 三模式（模式间切换互斥）：① 单独指定一个音调；② 范围（起~止，闭区间，UI 用音名如 `C4~D4`）；③ 多选多个音调。内部映射为 key 数值集合 |
| 音量 velocity | 两模式（互斥切换）：① 范围（min~max，0–100）；② 多选具体音量值（勾选若干 0–100 的取值） |

- 条件面板带「重置」「清空全部条件（= 匹配全部音符）」按钮。
- 条件与模式选择**持久化**（`localStorage`），但"匹配结果"不持久化。

### 4.4 匹配、导航与反馈

- **匹配顺序**：按 `(tick 升序, layer 升序)` 排序；导航从当前匹配下标开始循环（下一个到尾回到第一个）。
- **初始查找锚点**：从播放头所在 tick 之后的第一个匹配开始；播放头不可用则从曲首开始。
- **命中反馈（假设，待确认④）**：自动选中当前匹配音符、滚动视图使其可见、并以独立高亮色（区别于选区高亮）标记当前匹配；导航时更新反馈。
- 浮层显示：`当前序号 / 匹配总数`（如 `3/12`）。
- **实时性**：画布内容变更（增删音符、替换）后自动重新计算匹配。

### 4.5 全选匹配

- 「全部选择」按钮 → `selectNotes(全部匹配 id)`（替换当前选区，非增量）。
- 与查找完成后的手动选区互不冲突。

### 4.6 替换

- 浮层内提供「查找 / 替换」模式切换（与条件面板共用条件区）。
- **替换目标属性**（与查找条件相同的三个属性，可为其中任意组合）：
  - 将匹配音符的 音色 / 音调 / 音量 分别替换为指定目标值（音调支持指定单一新音调；增强项可支持相对偏移 ±n）。
  - **不修改 tick / layer（假设，待确认⑤）**：替换为"指定音符"即替换其属性，位置保持不变。
- 操作按钮：
  - 「替换当前」：替换当前匹配音符，随后自动跳到下一匹配。
  - 「全部替换」：替换全部匹配音符（**一个撤销步骤**）；完成后刷新匹配集（已被替换的项可能不再满足条件）。
- 撤销：所有替换为普通可撤销操作（并入主撤销栈）。

### 4.7 边缘细节

- 匹配 0 个：导航按钮禁用，显示「无匹配」。
- 音符被删除/移动导致仍在其匹配集合中的项失效：导航时跳过失效项。
- FLS（FL Studio 风格列表视图）作为独立视图，暂不支持（待确认⑧）。

## 5. 数据模型与状态

```js
// 创作辅助配置（localStorage 持久化，键如 nbs_assist_config）
assistConfig = {
  brush: {
    mode: 'normal' | 'sustain',          // 对应 Tab，默认 normal
    normal: { 音量: 100 },
    sustain: {
      预览显示: true,
      延音长度: 5,
      覆盖逻辑: 'overwrite' | 'shrink' | 'skip',   // 默认 overwrite
      留空长度: 0,
      是否淡出: false,
      最小音量: 10,
      淡出样式: 'linear'                  // linear | easeIn | easeOut | quadIn | quadOut
    }
  },
  eraser: {
    mode: 'area' | 'chain',              // 默认 area
    area: { 清除半径: 3, 区域形状: 'circle' | 'square' },
    chain: { 同类判定: { 音色: false, 音调: false, 音量: false }, 数量限制: 64 }
  }
}

// 查找/替换（会话态 + 条件持久化；结果不持久化）
findState = {
  mode: 'find' | 'replace',
  conditions: { instruments: [], keys: {mode, values[]|range}, velocities: {mode, range|values[]} },
  replaceTargets: { instrument|key|velocity: ... },
  matchIds: [], currentIndex: -1
}
```

## 7. 交互规范（鼠标 + 触控一致）

- **悬浮窗**：桌面鼠标拖动头部移动；触控单指拖头部移动；点外部/Esc/× 关闭；双指在面板内滚动内容区。
- **延音预览**：与现有「触控点击=等效 Ctrl 多选 / 画笔滑动连续放置 / 橡皮滑动连续删除」约束不冲突；预览仅渲染、不改变数据与选区。
- **查找浮层**：输入控件聚焦时全局快捷键（含键盘钢琴）不响应；`Esc` 依次关闭浮层→退出。
- **横屏移动端**：创作辅助入口进入右侧抽屉（悬窗内容逻辑不变）。

## 8. 边界情况清单

1. 延音放置越界（tick 超出曲长/格子、layer 越界）→ 截断组。
2. `N=0`（延音长度 0）→ 仅放首音符，等价普通放置（无淡出）。
3. 覆盖逻辑中"障碍"判定以**放置时刻**当前音符表为准（预览按当前表静态显示）。
4. 一组延音放置中途撤销 → 整组回退（勿逐音符撤销）。
5. 连续清除遇到数量上限 → 静默停止，无报错；动画按阈值策略。
6. 查找替换造成重复匹配/自匹配（如"替换后仍满足条件"）→ 全部替换后重算匹配，避免死循环。
7. 大曲目（万级音符）匹配/全选/全部替换 → 匹配数组 + 批量更新接口，避免逐音符渲染。
8. 触控与鼠标事件路径在放置/清除切换时不得互相污染（沿用现有 `_touchMode`/`_mouseDown` 状态机）。
9. 面板开启时不应拦截画布其他交互（除面板覆盖区域与拖动手柄）。
